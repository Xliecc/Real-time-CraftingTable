# 实时工作台（Real-time CraftingTable）

> 纯客户端 × 服务端配合的 Fabric 模组，为原版工作台添加 3D 实时合成预览。
> 作者：Xliecc　｜　许可：MIT

📖 **[English README](README.md)**

## 功能
- **3D 实时预览**：打开 3×3 工作台合成界面，放入的材料以 3D 立体形式悬浮在对应槽位上方；配方成立时，合成结果浮在材料区上方并缓慢旋转。改配方即变。
- **关闭后保留**（可开关）：开启后关闭工作台界面时材料不退还，按位置保留在台面上，如同把工作台当容器——下次打开同一张工作台仍可查看或继续合成；保留状态在多人联机中同步。
- **大量自定义**：材料悬浮 / 平摊两种风格；波浪 / 同步 / 不浮动三种动画；朝向跟随玩家或固定不动；生长动画开关；渲染距离、大小、间距、高度、速度、幅度均可调（可适配各类材质包）。
- **性能友好**：闲置工作台每帧零成本；超出渲染距离的预览自动跳过；跨帧复用渲染状态，适配整合包。
- **局域网 / 独立服务器联机**：单机、LAN、独立服务器均可用；双方都装了模组时，材料状态、工作台朝向、保留物品会在客户端间正确同步。
- **Mod Menu 配置页**：全部动画参数经 Mod Menu + Cloth Config 图形化调节，保存即时生效，无需重启。

不新增任何物品 / 方块 / 配方 / 世界内容——纯视觉增强（客户端 × 服务端配合）。

## 依赖
- Minecraft **1.21.11**
- Fabric Loader ≥ **0.19.3**
- Fabric API
- 可选：Mod Menu + Cloth Config（提供配置界面；不装也能正常运行）

## 安装
将 `build/libs/Real-time CraftingTable-1.0.0.jar` 放入 `.minecraft/mods/` 即可。

> 提示：Mod Menu + Cloth Config 安装后可在 Mod Menu 里打开本模组的图形化配置页（可选依赖，不装也能正常运行）。

## 配置
- 打开 Mod Menu → 本模组 → 配置页，图形化调节。
- 或直接编辑 `config/real-time-crafting-table.json`（首次运行自动生成）。
- 主要可调项：总开关、浮动类型、可视化方式、朝向模式、渲染距离、材料/结果大小、高度、间距、速度、幅度、生长动画、关闭后保留材料等。
- 全部配置项的文案已中英本地化，随游戏语言切换。

## 联机
- 单机 / LAN / 独立服务器均可用。
- 服务端与客户端都安装时：材料的保留状态、工作台朝向、已存材料会在客户端之间正确同步；后加入的玩家也能看到已保留的预览。
- 仅客户端安装（连非模组服务器）时：预览渲染仍可用，但「保留材料」「方向同步」等依赖服务端的功能不生效。
- 独立服务器的大规模联机场景尚未经大规模实测，请按需自行评估。

## 构建
需要 JDK 21。

```bash
# Windows
gradlew.bat build
# macOS / Linux
./gradlew build
```

产物位于 `build/libs/Real-time CraftingTable-<version>.jar`（另产出 `-sources.jar` 源码包，供自愿分发）。

## 常见问题
- **预览没显示**：确认打开的是 3×3 工作台合成界面（不是背包 2×2）；视线上要能看到正在使用的工作台；检查 `enabled` 与 `renderDistance`。
- **装了 Mod Menu 但配置界面没出现**：需要同时安装 [Cloth Config](https://modrinth.com/mod/cloth-config)（自动随 Mod Menu 下拉）。
- **「关闭后保留」没生效**：主控此行为的开关在服务端配置——单机集成服务器即房主的配置，独立服务器即服务器文件配置。
